# Stomatološka ordinacija Vasiljević – sajt

Statički sajt, bez build koraka.

- `index.html` – početna
- `cenovnik.html` – cenovnik
- `vasiljevic/` – fotografije i logo
- `support.js` i `_ds/` – potrebni da se stranice prikažu, ne brisati

## GitHub Pages
1. Napravi novi repozitorijum i ubaci sve iz ovog foldera u korijen.
2. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Sajt je na `https://KORISNIK.github.io/NAZIV/`.

Sajt učitava React sa unpkg.com i fontove sa Google Fonts, pa treba internet.
